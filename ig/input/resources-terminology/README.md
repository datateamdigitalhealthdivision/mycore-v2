# MY Core-Owned Terminology

This directory is human-owned and never wiped by the build.

Use `resources-terminology/` for MY Core-owned `CodeSystem`, `ValueSet`, and `ConceptMap` JSON only.

Do not copy international code systems such as SNOMED CT, LOINC, ICD, or UCUM into this repository path. Those artefacts are ingested into Snowstorm, HAPI, and terminology services separately and must remain outside this folder.
