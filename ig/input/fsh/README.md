# FSH Authoring Stream

This directory is the authoritative human-authored source for MY Core
conformance content.

Profiles, extensions, value sets, code systems, and related artefacts are
migrating from generated JSON into FHIR Shorthand (`.fsh`) over time.

Do not hand-edit files in `../resources-legacy-migrated/`. That directory is
regenerated by the migration script and is wiped on every build.

The intended authoring flow is:

1. Keep the legacy-generated JSON in `../resources-legacy-migrated/` until the
   team decides to actively own a resource.
2. Convert that JSON resource to FSH with
   `../scripts/jsonresource-to-fsh.sh <resource-id> --exclude`.
3. Refine the generated `.fsh` in this directory and commit it through normal
   repository review.
4. Let the collision audit prove the resource is no longer being published from
   both streams at once.
