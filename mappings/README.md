# Mapping Assets

This directory contains the machine-readable migration layer for MY Core v2.0.

- `legacy-to-v2-canonical-mapping.csv`: crosswalk from legacy canonicals to the v2 publication line
- `duplicate-resolution-log.csv`: explicit record of duplicate and collision handling
- `profile-family-index.csv`: family-level index of migrated `StructureDefinition` artefacts
- `terminology-source-register.csv`: provenance register for migrated terminology artefacts
